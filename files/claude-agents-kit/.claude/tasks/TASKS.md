# Tareas

Formato: cada tarea es un checkbox con un id corto. El orquestador (Claude Code)
sigue el flujo descrito en el footer de CLAUDE.md para cada tarea, en orden,
de arriba a abajo, saltando las ya marcadas como hechas.

- [ ] **T001** — <Descripción clara y concreta de la tarea. Cuanto más específica, mejor cribado hace context-scanner.>
- [ ] **T002** — <...>
- [x] **T000** — Ejemplo de tarea ya completada (no se vuelve a procesar).
